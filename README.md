This is the website for Seahorse Centaur Studios, which is needed in order to get the Apple Developer account set up.

The website integrates with a couple of tools. 
1. MailerLite: there is a newsletter signup link on the main page that connects to MailerLite. it sends them a confirmation-email where they have to click a link to finalize the sign-up. The free tier allows up to 2500 emails per month and 200 subscribers.
2. Web3forms: this is used to manage the support form. it supports up to 250 submissions per month on the free tier.
